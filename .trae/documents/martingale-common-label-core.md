# 马丁价格标签统一到 common

## Context
用户要求标签全部核心逻辑位于 `data_process/common.py`，其它模块引用。标签是纯价格路径结果，不计算杠杆、资金、仓位、手续费或收益；这些属于模拟端。

## 已确认语义
- 开仓价格取当前 K 线 close；从下一根 K 线开始重放，不使用入场当根的 high/low 判断未来事件。
- 0：未加仓直接止盈；1～8：加仓相应次数后止盈。
- 一旦达到第 9 次加仓档位，立即返回 9，不等待止盈。9 是封顶触达标签，不是“第9次加仓后止盈”。加仓次数不含底仓。
- 数据末尾仍未止盈且未触达第9层，标签为空并标记未结束；保留已触达最大档位。非法输入不归入任何有效类别。
- 延用原扫描的绝对入场价斐波那契档位；所有档位必须有限且为正。默认1%步长第9次偏移89%，不生成第10次144%档位。
- 无加仓时沿用当前扫描的初始价格止盈目标，加仓后止盈价回退前一档；将初始止盈目标表达为价格比例，不从仓位及费用反解。
- 优先重放有效1分钟数据；剩余歧义统一采用做多 Open→Low→High→Close、做空 Open→High→Low→Close，事件路径与模拟允许层数K无关。细周期缺失时使用同一固定路径并记录来源。

## 实施步骤
1. **common 提供纯价格标签核心**
   - 从 `trade/sim/martingale_scan.py` 复用并迁入网格价格规则、价格触达与路径重放逻辑，移除核心对仓位、净利润、杠杆和费用的依赖。
   - 提供独立马丁标签参数、序列化、单起点计算、批量计算和 `attach_label` 分派。common 不导入 trade 的加载器、数据类型或模拟模块。
   - 使用下一根开始的未来路径；处理跳空及单根穿越多档；触达第9档立即结束。
2. **输出可复用的最小信息**
   - 输出 label、状态、最大触达档位、入场价、结束时间/索引及止盈价格。
   - 为扫描消费保留各档首次触达时间/索引及实际触达价格等必要价格信息；不存仓位成本、资金费用或风险快照，不永久保存全部逐笔事件。
   - common 只提供价格路径及事件信息，不计算收益和杠杆。
3. **扫描与报告引用标签**
   - `trade/sim/martingale_scan.py` 保留调度和模拟端资金、费用、收益计算；引用 common 标签核心与价格事件，不再重复定义标签规则。
   - `experiment/martingale_layer_scan.py` 每方向生成一次封顶9标签，复用各档价格事件投影 K2～K6：M≤K 且已止盈则成功；M>K 则在第K+1档击穿；未结束周期按已触达档位判断是否已击穿小K，否则未结束。
   - label=9 只可确认K≤8的击穿；不得将其用于宣称K9止盈或击穿，不构造第10档。
   - 收益、持仓、费用及杠杆由模拟端独立计算，标签模块不承载这些逻辑。消费端不得混用旧open入场及按K择差路径的产物。
   - `data_process/preparation.py` 接入马丁参数、细周期加载及标签统计，不套用三分类阈值列；训练任务尚不支持该标签时明确报错，本次不扩展模型类别。
   - 更新 `experiment/martingale_report.py`、`experiment/martingale_regime_filters.py` 等实际消费入口。另一套 `martingale_engine.py`/通用回测策略保持不变。
4. **产物隔离与范围控制**
   - 标签元数据记录方向、价格规则、步长、初始止盈价格比例、close入场、封顶9语义、路径规则及主细周期数据范围/指纹；资金、费用、杠杆不进入标签参数。
   - 模拟产物单独记录K及资金执行参数；旧结果保留，不声称兼容或数值一致。
   - 先完成小样本端到端验证，不自动启动全历史重算，不改写现有研究结论，不增加增量缓存系统。
